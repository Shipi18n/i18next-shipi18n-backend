# i18next-shipi18n-backend — DEPRECATED

> [!IMPORTANT]
> This i18next backend called the **hosted Shipi18n API, which has been shut down.** It is no longer
> maintained and there is no v2.

Translate your locale files **at build time** with the open-source, bring-your-own-LLM
[`@shipi18n/cli`](https://www.npmjs.com/package/@shipi18n/cli) instead — no runtime backend, no hosted
API, your own Anthropic/OpenAI key:

```bash
npx @shipi18n/cli translate ./locales/en.json -t es,fr,de
```

- **Source & docs:** https://github.com/Shipi18n/shipi18n

The hosted-API documentation previously shown here no longer applies.
